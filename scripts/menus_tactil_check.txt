# Verificacion: los menus se manejan CON EL DEDO (Android)
# Uso:  MANTLE.exe --touch --script scripts/menus_tactil_check.txt
#
# Por que existe: hasta la pasada de Android toda la navegacion era MoveUp/Down/Confirm/
# Cancel y el tactil no emitia ninguna de las cuatro. En un telefono no se podia ni pulsar
# "Nueva Partida". La regresion a proteger es esa.
#
# Regla: tocar una fila = elegirla Y confirmarla. En Opciones, la mitad IZQUIERDA de la
# fila baja el valor y la DERECHA lo sube. En las decisiones (cartas, encuentros) hacen
# falta DOS toques: el primero elige, el segundo decide.
#
# En MOVIL no se pinta ningun boton como elegido (no hay cursor: se toca el que se quiere)
# y lo unico que cambia de aspecto es el que esta bajo el dedo. De ahi las capturas M4/M5.
#
# Reparto TACTIL (unidades de juego, las mismas que pinta cada render_*):
#   Titulo    rejilla 2x4 colgada del CENTRO. Celda izq. x 62..154 (centro 108), celda
#             dcha. x 166..258 (centro 212).
#             0 Nueva Partida (108,77)   4 Prologo   (212,77)
#             1 Continuar     (108,102)  5 Opciones  (212,102)
#             2 El Santuario  (108,127)  6 Controles (212,127)
#             3 El Codice     (108,152)  -- hueco de las ofrendas en (212,152)
#             El canal entre columnas (x 154..166) es zona muerta a proposito.
#   Opciones  ventana de 6 filas, hueco k -> y = 48 + k*21 (centros 52, 73, 94, 115, 136,
#             157), placa de x 16 a 304. Con --touch las filas son 12 (Musica, Efectos,
#             Auto-mira, Sensibilidad, Vibracion, Joystick de apuntar, Tam. botones, Opacidad,
#             Zurdo, Ahorro bat., Idioma, Volver — las cuatro de los controles tactiles
#             desde 2026-10-03), asi que "Volver" (indice 11) solo se alcanza tras
#             recorrer 6 pasos.
#   Cartas    choice_card_rect: 3 cartas de 92 de ancho, centro de la 2a en x=160, y=77
#
# GATES (log):
#   1. SAVEDUMP final:  musica=0.40  sens=6      <- ajustado a dedo, mitad izq/dcha
#   2. `Scene change` al tocar "Nueva Partida"   <- la fila del titulo responde
#   3. `Item taken:` tras tocar DOS veces la misma carta
#   4. Una linea `Menu tap: pantalla=P fila=F` por toque, con los pares que dice cada
#      bloque, y NINGUN `fila=-1` salvo el del primer toque (ver abajo)
#   5. Cero `Input: tap descartado sin leer` fuera de ese primer toque
#   6. El bloque de ARRASTRE no puede producir ni un `Menu tap`: un arrastre recorre la
#      lista, y lo que recorre la lista no pulsa ademas la fila
