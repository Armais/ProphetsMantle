# Verificacion Track 2: las reliquias van a UN SOLO slot (GDD 7.3)
# Uso:  MANTLE.exe --script scripts/reliquias_check.txt
#
# Las dos reliquias del juego:
#   id 6  Tablas de la Ley  -> FaithSystem::floor_value = 25 (la fe no baja de 25)
#   id 7  Arca del Pacto    -> Player::miracle_power  = 1.5 (+50% dano de milagros)
#
# El GDD decia "1 slot" y el codigo lo documentaba pero no lo imponia: se podian llevar
# las dos y sus efectos se ACUMULABAN, porque grant_item los aplicaba al conceder. Ahora
# se RECALCULAN desde relic_slot (Player::apply_relic_effects), que es la unica forma de
# que quitar una reliquia deshaga lo suyo.
#
# Que hay que ver en el LOG (lineas LOADOUT de `stats`, que ahora traen la reliquia y sus
# DOS efectos: son lo unico que no se deduce de la lista de objetos):
#   sin_reliquia     reliquia -                  (suelo fe 0,  milagros x1.00) objetos: -
#   con_tablas       reliquia Tablas de la Ley   (suelo fe 25, milagros x1.00) objetos: Tablas
#   con_arca         reliquia Arca del Pacto     (suelo fe 0,  milagros x1.50) objetos: Arca
#   vuelta_a_tablas  reliquia Tablas de la Ley   (suelo fe 25, milagros x1.00) objetos: Tablas
#
# Los tres gates estan en esas lineas: el efecto de la reliquia SUSTITUIDA vuelve a su
# base (suelo 0 / x1.00), la lista de `objetos` no acumula las dos, y la cosa es
# reversible. En las capturas, la fila de objetos del HUD marca con un recuadro claro la
# que llevas puesta, y la carta de eleccion de una reliquia dice a cual sustituye.
