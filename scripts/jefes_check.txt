#
# GATES DEL LOG (exit 0 NO es un gate):
#   1. "Boss sheets cap N: propia" en los diez (las nueve hojas boss_*.png + acab.png y
#      jezabel.png del cap. 5: "propia + pareja propia"). Sin la hoja, "prestada" y una
#      linea "Boss sheet ausente: ..." — y CERO "Failed to load".
#   2. "Boss <nombre> spawned: hp N, hoja propia, escala 1.40" una vez por capitulo (dos
#      en el 5: Acab y Jezabel).
#   3. Una linea "Hazard <Tipo> spawned (...)" por lo menos de: Lane (1, 5, 7, 10),
#      Circle (2, 3, 5, 6, 9, 10), Ring (3, 4, 6, 7), Push (4), Cone (5, 8), Pool (6, 9).
#   4. Fases: "Boss Capitan de Acab phase 1", "Boss Sacerdote de Baal phase 1", "Boss Sumo
#      sacerdote de Baal phase 1", "Boss Tu Propia Desesperacion phase 1/2/3" (las tres),
#      "Boss Acab phase 1 (enfurecido...)", "Boss Espiritu de Corrupcion phase 1",
#      "Boss El Acreedor phase 1 (la deuda)", "Boss La Muerte phase 1", "Boss Guiezi el
#      Codicioso phase 1", "Boss Ben-adad de Siria phase 2 (la hueste celestial...)" y
#      "soldados cegados 6 s".
#   5. Los estados de cada estrategia: "stunned" (cap. 1), "idolos en pie" e "idolos
#      derribados" (cap. 2), "ritual del corro" (cap. 3), "canaliza la curacion" (cap. 5),
#      "se sumerge" y "emerge" (cap. 6), "la deuda se cierra" (cap. 7), "sin resuello"
#      (cap. 8), "se teletransporta (2 senuelos)" y "lanza la plata" (cap. 9),
#      "artilleria" y "lluvia de flechas" (cap. 10).
#   6. Diez "Boss <nombre> defeated in T s" y diez "Cell N cleared (Boss)": la arena se
#      cierra aunque haya idolos, senuelos o plata (mueren con el jefe).
#   7. Cero "Hazard ... DESCARTADO" (la piscina de 64 no se llena).
#
# CAPTURAS (mirar CADA una): jNN_* — telegrafos en el suelo (relleno que se llena, borde

# translucidos de Guiezi y los sirios cegados (palidos) del cap. 10.
