# --- Stick derecho (GDD 4.2 "opcional"): apunta DESDE EL PRIMER PIXEL ---
# Con la opcion apagada hay que arrastrar TOUCH_DRAG_AIM (6 unidades) para que el
# apuntado registre; con ella encendida el stick nace ya activo y se dibuja. Aqui se
# arrastra UNA unidad, que esta por debajo de cualquier umbral. Lo que se lee NO son las
# capturas sino el LOG: tiene que salir UNA sola linea
#     Touch aim ON (right stick)
# y ninguna "(drag threshold)". Comparar las dos capturas a ojo no vale: el mapa pone
# altares dorados por ahi y su adorno se confunde con la mira (dos intentos perdidos).
#
# La secuencia buena del log, entera:
#   rstick = 0  /  Touch aim ON (drag threshold)   <- hold+drag de 45 unidades: engancha
#   rstick = 0  /  (ninguna linea)                 <- arrastre de 1 unidad: NO engancha
#   rstick = 1  /  Touch aim ON (right stick)      <- el MISMO arrastre de 1 unidad si
#   rstick = 0
#
# Ojo, y costo una pasada: el umbral NO es fijo, es TOUCH_DRAG_AIM entre la
# SENSIBILIDAD, y la sensibilidad vive en el guardado y sobrevive entre sesiones. Con
# sensibilidad 8 el umbral baja de 6 a 4,2 unidades y un arrastre de 5 lo cruzaba solo,
# haciendo que las dos capturas salieran iguales.
#
# Ojo con DONDE se toca: la primera version de esta prueba caia sobre un altar del mapa
# y el adorno del suelo se confundia con la mira. (232, 100) es suelo raso. Y sobre todo,
# la sonda NO puede caer encima de un boton (ni de su margen de dedo): se comprueban antes
# que el "tap = ataque" y se comen el gesto entero. El mas cercano es ARMA, en (252,112)
# con radio 11 + 4 de margen: (232,100) queda a 23 de su centro.
