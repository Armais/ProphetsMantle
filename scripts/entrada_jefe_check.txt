# Uso:  MANTLE.exe --script scripts/entrada_jefe_check.txt

# Antes se saltaba de golpe del mundo a la escena guionizada del jefe. Ahora, delante de
# esa escena, el profeta ENTRA andando en la arena y la camara se adelanta hacia el jefe.
#
# `entrada` es OBLIGATORIO y va antes del `walk`: el autoplay suprime el dialogo del jefe
# (los guiones cronometran las peleas) y con el se suprimiria tambien el paseo, que es
# justo lo que hay que mirar.
#
# GATES DEL LOG, en este orden y sin nada entre medias:
#     Arena sealed: boss cell N
#     boss approach start: chapter 1, (x,y) -> (x,y)
#     boss approach end (completo)
#     Jefe 1 ...                       <- la escena, SIEMPRE despues del paseo
# Que la escena jamas salga ANTES de `boss approach start` es el gate que manda: es el
# corte que se venia a quitar.
#
# GATE VISUAL: 80 (recien sellada), 81 (a mitad del paseo) y 82 (primer frame de la
# escena). El encuadre de 82 tiene que ser el MISMO que el del final del paseo — por eso
# el destino del paseo es el punto al que `start_scene` teletransporta al profeta y no
# otro: si no coincidieran, el salto seguiria ahi, dos segundos mas tarde.
#
# Geometria (scripts/CLAUDE.md): `goto boss` deja BAJO el recinto; el vano esta en
# (1568..1632, 192..208) y la celda B es (2,0) en todos los capitulos, asi que
# `walk 1600 150` es lo que mete al profeta dentro y dispara `enter_arena`.
