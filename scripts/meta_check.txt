# Uso:  MANTLE.exe --script scripts/meta_check.txt

# Hasta ahora las 8 mejoras de El Santuario eran solo cifras y el unico desbloqueo entre
# partidas era el epilogo. Ahora hay 12 mejoras y cuatro de ellas meten un objeto en el
# sorteo de cartas:
#   [8]  El Arco del Rey        ->  16 Arco de Joas        90
#   [9]  El Remedio del Profeta ->  17 Higos de Ezequias  110
#   [10] La Mesa de Eliseo      ->  21 Panes de Cebada    140
#   [11] La Sombra que Vuelve   ->  20 El Reloj de Acaz   260
#
# Que hay que ver en el LOG:
#   SAVEDUMP ... items_desbloq=0x0        <- de partida, los cuatro bloqueados
#   Meta unlock: item 16 (Arco de Joás)   <- al comprar
#   SAVEDUMP ... items_desbloq=0x330000   <- bits 16, 17, 20 y 21 puestos
#   ... y el mismo valor DESPUES de borrar la partida: es meta, no se pierde al morir.
#
# Gates:
#   1. `unlocks 0` + los cuatro bits a cero: los objetos bloqueados no salen en `cards`.
#   2. Comprar pone el bit y lo dice en pantalla.
#   3. El desbloqueo sobrevive a delete_save.
#   4. El panel se lee entero a 320x180 CON 12 filas (capturas 50 y 51: hay scroll).
