# Gates del log (exit 0 NO es un gate):
#   1. "Cinematica del Ascenso (asccine, escena 0)" x2 (pasada ES y pasada EN).
#      El log solo se imprime al ENTRAR con el comando; las seis escenas de cada
#      pasada se recorren con confirm y su prueba son las capturas as01..as06.
#   2. Cero "Cinematic: falta la capa" — los 12 PNG de las cuatro estampas existen.
#   3. Cero "TEXT TRUNCATED" — las nueve frases del pasaje + la linea de la
#      herencia caben en la franja, en ES y en EN.
#   4. "Unloaded texture" tras salir de la cinematica — sus capas no quedan en VRAM.
#   5. "Cinematica del Ascenso suprimida (autoplay): paginas de texto" — el flujo
#      real bajo autoplay sigue siendo el texto de siempre: ascension_check y
#      logros_check no ven cambio.
#   6. "Ascension: le seguiste 3 de 3 veces, doble porcion=si" — la herencia
#      queda como estaba (misma condicion que vigila ascension_check).
#
# `asccine [n]` es el UNICO camino a la cinematica bajo autoplay, y la deja
# PARADA (como chintro): se avanza con `press confirm` y se sale con `press
# cancel`. Solo mira: al salir NO se reparte ninguna herencia.
