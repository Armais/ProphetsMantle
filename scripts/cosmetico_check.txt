# Verificacion Track 9: cosmeticos (skins del cayado) y la puerta de contenido
# Uso:  MANTLE.exe --script scripts/cosmetico_check.txt
#
# Las tres cosas que el GDD mete en la misma tabla y que NO son la misma:
#   * Premium 4,99: NO necesita una linea de codigo. Es un precio en la ficha de la
#     tienda. Se documenta y se cierra.
#   * Cosmeticos: esto. Sin ninguna dependencia externa, comprados con OFRENDAS (la
#     moneda que ya existe) y no con dinero. "NO pay-to-win" lo dice el propio GDD: una
#     skin es un TINTE sobre el proyectil y el fogonazo, y no toca ni una cifra.
#   * Free-to-Start (Acto I gratis / Acto II de pago): necesita entitlements y tienda.
#     Aqui solo queda la PUERTA (`SaveData::entitlements`), que hoy se concede sola.
#
# Que hay que ver en el LOG:
#   SAVEDUMP ... skins=0x1/0 derechos=0xFFFFFFFF   <- de partida: solo la skin 0
#   SAVEDUMP ... skins=0xF/2 ...                   <- las cuatro, con la 2 equipada
#
# Gates:
#   1. Comprar la mejora desbloquea la skin y el bit sobrevive a delete_save.
#   2. La fila "Cayado" de Opciones NO aparece con una sola skin (una fila que solo
#      ofrece lo que ya llevas no es una opcion) y SI aparece con varias.
#   3. El disparo cambia de color en partida (capturas C2 y C3).
